# NetraSaathi plan (repo copy)

The living plan is the shared doc "NetraSaathi Build Plan" (Plan tab). This file
keeps the parts the code depends on.

## Must, by Sun 8 Nov 2026 (sprint submission)

1. Hindi voice interview that adapts, with read-back
2. Danger-sign rules that stop the flow at once
3. Distance chart (tumbling E at 3 m), pinhole step, clock dial
4. Near test: phone brought closer while the camera measures distance
5. Profile card: Green, Amber or Red, with reasons
6. Optometrist portal: queue, case view, approve or edit
7. Pilot at one store with 10–20 people

## Should, by Tue 1 Dec 2026 (Grand Finale, Bangalore)

Second language; optometrist voice reply; WhatsApp result card; read-aloud test and
Amsler grid; quality checks; offline mode; bigger pilot and 100-phrase word list.
